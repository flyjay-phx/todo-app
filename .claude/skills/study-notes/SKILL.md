# 수업 후 노션 정리

1. 레슨 본문(링크나 붙여넣은 텍스트)과 오늘 실제로 한 실습을 먼저 확인한다. 하지 않은 것은 한 것으로 쓰지 않는다.
2. 요청 종류에 맞춰 쓴다.
   - **학습내용정리**: 한 줄 요약 + 번호 소제목 6~8개(개념, 실습, 안전·주의) + "아직 못한 것 / 남은 것" 섹션
   - **의문 및 토론**: 질문 5~6개. 각 질문마다 [레슨 내용 / 실습에서 본 것 / 토론 포인트]로 나눈다
   - **오늘의 회고**: 회고 질문 3개. 본인 답이 없으면 지어내지 말고 한 줄씩 물어본다
3. 출력은 노션에 그대로 붙여넣을 수 있는 마크다운(# 제목, ## 번호 소제목, - 불릿), 한국어 존댓말, 한 페이지 분량으로 한다.
4. 팀원 정리가 있으면 빠진 개념만 비교해 알려 준다.
5. 레슨에 없는 수치나 사실을 만들어 넣지 않는다. 출처 목록과 역사 이야기 같은 세부는 버린다.
